# 血圧・脈拍管理 Web アプリ

スマホから血圧・脈拍を記録・管理できる静的Webアプリです。サーバー不要で、ブラウザだけで動作します。

## デモ

https://masahiro-ikezaki.github.io/BloodPressure/

## 機能

- **記録**: 血圧（上/下）、脈拍、測定腕、服装、メモを入力
- **グラフ**: 血圧・脈拍の推移を折れ線グラフで表示（7日/30日/90日切替）
- **一覧**: カード形式で記録を一覧表示、編集・削除
- **CSV出力**: BOM付きUTF-8でExcel対応のCSVダウンロード
- **バックアップ**: JSONエクスポート/インポート
- **マルチユーザー**: 2〜3名を切り替えて管理

## 使い方

`index.html` をブラウザで開くだけで動作します。

GitHub Pages でホスティングする場合は、リポジトリの Settings → Pages から有効化してください。

## 技術スタック

- HTML5 / CSS3 / Vanilla JavaScript（ES6+）
- [Chart.js](https://www.chartjs.org/) v4（CDN）
- データ保存: localStorage（JSON形式）

## モバイルファースト設計

- 下部タブバー（親指操作に最適化）
- 大きな数値入力欄
- トグルボタンによる腕・服装の切替
